Developed a Smart Parking System using OpenCV, TensorFlow, and Convolutional Neural Networks (CNN) to automatically detect and classify parking spaces as empty or occupied from parking lot images. The system uses advanced Computer Vision techniques such as image preprocessing, edge detection, contour analysis, and automatic parking slot coordinate detection to identify parking regions without manual intervention. A CNN model was trained on a custom parking dataset to improve occupancy prediction accuracy. The project also includes real-time visualization where empty parking slots are highlighted in green and occupied slots in red, along with automatic counting of available spaces. This project demonstrates practical applications of Deep Learning and Computer Vision in smart city infrastructure, automated parking management, and intelligent traffic systems.
